# Notes app specification

## CAP-1 — Write and keep a note

Typing is never blocked by a save, and no keystroke is lost to a crash.

## CAP-2 — The same notes everywhere

A note written on one device reaches the others without the user doing anything.

## CAP-3 — Offline edits survive

Two devices editing the same note offline both keep their work.
