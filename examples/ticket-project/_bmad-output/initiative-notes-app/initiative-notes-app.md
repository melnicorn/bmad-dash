# A notes app you can trust offline

## Description

A small notes app that works with no network, syncs when it can, and never
loses a keystroke. This example exists to show the BMAD 6.13+ ticket-tree
layout: an initiative holding epics, each epic holding entries in build
order, with status living in each ticket's build plan.

## Outcome

Someone writes a note on a plane and finds it on their laptop that evening.
