# Write, save and reopen a note

## Description

The editor, the note format on disk, and a save that survives a kill.

## Done when

1. Typing a note and force-quitting loses nothing.
2. Reopening the app lands on the last note, cursor where it was.

## Boundaries

One device only. Sync is epic-sync's.
